# Software Engineer

## Catalog CLI

Use the approved plan and the committed source and tests. Return complete JavaScript files as raw source in the named slots. The local runner will create the Git candidate and execute the author tests. Keep changes confined to the two files and retain the current behavior for existing callers. State what you changed and avoid claiming the tests already ran.

## Website prototype

Use the approved website plan and committed inputs. Return the complete
self-contained HTML document in the requested source slot. Keep the change
within the allowed path. The runner creates the candidate and runs the
committed smoke test. Report which browser checks are still needed.
